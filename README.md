# Rosacea vs Acne Skin Classifier

An AI-powered web app that classifies skin images as **Rosacea** or **Acne**, deployed as an interactive Streamlit application.

## How to Use

1. Open the deployed app link (below).
2. Upload a clear image of the skin condition (JPG or PNG).
3. The app displays the prediction (Rosacea or Acne) with a confidence score.

---

## Deployment

Deployed on Streamlit Community Cloud: https://rosacea-acne-classifier-b5u8mqnnd5mdzk9iwzgwwp.streamlit.app/, connected directly to this GitHub repository.
